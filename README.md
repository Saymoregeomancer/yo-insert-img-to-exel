# yo-insert-img-to-exel

Пункт контекстного меню Провідника Windows, який вставляє картинки в ексель-файл.

## Як працює

Клацніть правою кнопкою по папці (або по порожньому місцю всередині неї) →
**«Вставити картинки в ексель»**. У цій папці скрипт шукає:

* ексель-файл, назва якого складається **тільки з цифр** (`12345.xlsx`, `.xlsm`, `.xls`);
* папку, у назві якої є **«обк»** (регістр не важливий) — у ній лежать картинки.

Для кожного рядка, починаючи з 2-го, береться значення з колонки **A**; якщо в папці
«обк» є картинка з такою назвою (`.png`, `.jpg`, `.jpeg`, `.bmp`, `.gif`), вона
вставляється в колонку **D**, масштабується під ширину колонки, а висота рядка
підганяється під картинку. Файл зберігається на місці.

Якщо у вибраній папці такої пари немає, перевіряються її підпапки (перший рівень),
тож можна обробити кілька папок одним кліком по батьківській.

Налаштування (аркуш, колонки, початковий рядок) — на початку `insert_img_to_excel.py`.

## Вимоги

* Windows + встановлений Microsoft Excel (робота через xlwings);
* Python 3.10+ у `PATH`.

## Встановлення

1. Завантажте архів з [Releases](https://github.com/Saymoregeomancer/yo-insert-img-to-exel/releases)
   і розпакуйте в постійне місце (меню посилається на цю папку).
2. Запустіть `install.bat` — встановить залежності (`requirements.txt`) і додасть пункт меню.
   Права адміністратора не потрібні (запис у `HKCU`).

Видалити пункт меню — `uninstall.bat`.

Запуск без меню: `python insert_img_to_excel.py "C:\шлях\до\папки"`.

> Повторний запуск на тому ж файлі вставить картинки ще раз поверх наявних.
